# Workspace rules for AI assistants

## Start here

1. Read `10_MEMORY/INDEX.md` and `20_PROJECTS/INDEX.md`.
2. Read `20_PROJECTS/LIFE_OS/TINA_NOW.md` only for cross-project handoff or current priorities.
3. Open the selected project's README.
4. Load only the exact canonical source required by the task.
5. Do not scan archives, event logs, or sensitive folders by default.

## Source precedence

1. The user's current explicit instruction.
2. Active verified facts in canonical memory.
3. Current project policy and status.
4. Task-specific sources.
5. Historical logs, generated summaries, and archived material.

## Privacy

- Never invent personal facts.
- Never store secrets here.
- Separate fact, assumption, external claim, question, and recommendation.
- Do not transmit private or sensitive content without task-specific authorization.
- Preserve originals and archive superseded evidence.

## Write-back

- Verified reusable fact → canonical memory.
- Current priority or blocker → current state/status.
- Project decision → project decision log.
- Historical action → event log.
- Temporary model output → generated cache.
- Uncertain claim → open loop with provenance.
