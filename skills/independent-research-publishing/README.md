# 📚 Independent Research Publishing Skill

**Original idea → verifiable literature → working paper → GitHub → Zenodo DOI → future versions.**

[Full reusable SKILL](SKILL.md) · [Zenodo official quick start](https://help.zenodo.org/docs/get-started/quickstart/) · [Example: The AI Productivity Trap](../../research/ai-productivity-trap/README.md)

A compact research publishing playbook created from a first-time independent author's actual publication workflow and its problems.

## Six steps
1. Capture the author's idea and anonymization boundaries.
2. Search existing literature and separate observation, hypothesis and evidence.
3. Produce an author-approved, versioned working paper with references and transparent AI disclosure.
4. Put complete, inspectable source and citation/version notes in GitHub.
5. Archive the **full manuscript file** in Zenodo, verify upload, publish with authorization, read back actual DOI.
6. Update GitHub citation links and use Zenodo versions for changes.

## Lessons from the first publication
- A GitHub page is already public, but is not an academic journal acceptance or DOI.
- A Zenodo record description or URL cannot substitute for the full attached manuscript.
- Browser automation may successfully fill metadata but fail on an operating-system file picker; keep the record a draft rather than falsely claim it was published.
- A DOI is only valid once assigned by the repository and independently verified.
- The work and its research ideas remain attributable to the human author.

## Reuse
Ask an assistant to follow the SKILL.md file, and provide only your idea, chosen public author name and scope of private details. Subsequent ideas can reuse the same workflow without making new parallel instructions.
